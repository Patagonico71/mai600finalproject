# AI Usage Disclosure

For: MAI 600 — Module 6 Final Project Proposal
Project: Local RAG Assistant for Customer Support Ticket Triage

| Item | Response |
|---|---|
| **AI tools used** |Claude for brainstorming structure and reviewing clarity; Hugging Face for model and embedding research; Ollama, FAISS, and Sentence-Transformers for the planned prototype., ChatGPT: for translation to English some phrases writing in Spanish, and for improve grammar  |
| **How AI was used** | To organize the proposal into the required sections, tighten wording, run an initial review of the dataset, and brainstorm safe evaluation questions. |
| **Prompts used (examples)** | "Suggest evaluation metrics for a RAG proposal built on a customer support ticket dataset." / "Review this dataset and report row counts, categories, and missing values." / "Rewrite this section to read clearly for a class assignment." |
| **Limitations or failures noticed** | Early suggestions sometimes proposed using the first ticket dataset as a knowledge base, even though its resolution text was randomly generated filler. This was caught during the data review and the dataset was replaced with one that has real agent answers. |
| **Academic integrity statement** | AI was used as a learning and support tool, not as a replacement for the student's own work. All decisions, checks, and the final wording are the student's responsibility. |
